# KannuRAPPER Premium Portfolio

Static portfolio website for KannuRAPPER, built with plain HTML, CSS, and JavaScript using the Rembrandt Dark Minimalism direction from the master specification.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploying to Vercel

This project does not need a build step.

- Framework preset: `Other`
- Build command: leave empty
- Output directory: `.`
- Install command: leave empty

## Files

- `index.html` - semantic page structure and SEO metadata
- `styles.css` - responsive visual system and layout
- `script.js` - mobile navigation, sticky header state, and scroll reveal behavior
- `assets/images` - hero and track artwork
